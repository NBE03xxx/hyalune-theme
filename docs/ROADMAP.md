# Hyalune：ロードマップ

実装済み機能と予定を区別します。以下の予定は、現在のインストーラーで選択できる機能ではありません。

| 項目 | 現在 |
| --- | --- |
| GNOME Shell / GTK3 / GTK4 / libadwaita Dark | 確認済み環境向けプレビュー |
| 独自ぼかし拡張 | 任意機能。単一画面・100％表示を中心に確認 |
| 既存の対応GTK Flatpak自動適用 | 初回導入に統合済み。後追加は個別CLI |
| 共通インストーラー | 実装済みプレビュー。機種固有指定不要。環境照合・保全・一括解除・復旧・旧記録移行をVMで検証 |
| GDM | 未実装。第4層として独立した任意導入を予定 |
| 管理アプリ | 未実装 |
| Hyalune Light | 未実装。現在はHyalune Darkのみ |

## 共通インストーラーと今後の検証

Git clone後の共通入口から、機種固有の`--target`なしで導入・更新・状態確認・解除・復旧とFlatpak操作を行えます。開発機のホスト名・DMI・固定UID・ディスク名に依存する照合を、対応OS・GNOME・Wayland・通常ユーザーなどの条件確認へ置き換えました。

既存GTK CSS・リンク・設定を保全し、競合時は停止します。基本テーマと管理Flatpakの一括解除・復旧を維持し、旧VM／実機試用の復元情報も引き継ぎます。任意効果の実行時も共通のOS・Shell・Wayland条件と適用記録を確認します。

新しい共通入口はVMの専用環境で検証しています。今後は異なる実機構成での導入・復元と日常利用の確認を広げます。ぼかしの単一画面・倍率・アクセシビリティ条件は引き続き別に判定します。[操作と確認範囲](INSTALL.md)

## GDM

第1層Shell、第2層GTK、第3層拡張と分けて、ログイン画面を第4層として扱います。システム資源への変更は明示選択と別の権限・保全・復元を必要とする設計を予定しています。現在の導入・解除ではGDMへ触れません。

## 管理アプリ

Shell、GTKアプリ、拡張機能、GDM、Flatpakの不透明度・色合いを連動して調整できる画面を予定しています。同じ数値がすべての描画系で同じ見え方になるとは仮定せず、可読性と対応範囲を表示します。

テーマ導入後に追加したFlatpakを検出し、対応状況・競合・起動状態を確認して選択適用できるようにします。既存CLIの所有記録・共通ロック・復旧処理を再利用し、別の管理系で上書きしません。GDMをユーザーセッションの変更と一括で実行しません。

## Hyalune Lightと外観の切り替え

Hyalune Lightとして、明るい背景での文字・境界・重なりの読みやすさを別途検証し、Hyalune Darkと同様に復元可能な形で追加する予定です。現行DarkをLight対応済みとは扱いません。

将来の切り替えはGNOMEの設定画面のDark / Light選択への連動を第一候補とします。Shell・GTK・拡張・Flatpakを安全に連動させることが複雑な場合は、Hyaluneの管理アプリから切り替える方法を検討します。切り替え機能の設計・実装・検証は今後の工程であり、今回の改称には含めません。
