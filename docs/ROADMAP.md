## 共通インストーラーと今後の検証

Git clone後の共通入口から、機種固有の`--target`なしで導入・更新・状態確認・解除・復旧とFlatpak操作を行えます。開発機のホスト名・DMI・固定UID・ディスク名に依存する照合を、対応OS・GNOME・Wayland・通常ユーザーなどの条件確認へ置き換えました。

既存GTK CSS・リンク・設定を保全し、競合時は停止します。基本テーマと管理Flatpakの一括解除・復旧を維持し、旧VM／実機試用の復元情報も引き継ぎます。任意効果の実行時も共通のOS・Shell・Wayland条件と適用記録を確認します。

新しい共通入口はVMの専用環境で検証しています。今後は異なる実機構成での導入・復元と日常利用の確認を広げます。ぼかしの単一画面・倍率・アクセシビリティ条件は引き続き別に判定します。[操作と確認範囲](INSTALL.md)

## GDM

第1層Shell、第2層GTK、第3層拡張と分けて、ログイン画面を第4層として扱います。KVMとThinkPad T16 Gen 4で明示選択する独立した入口を実装しました。専用の権限・保全・所有記録・復旧処理を使い、通常の導入・解除ではGDMへ触れません。他の実機は未確認で、現在の入口では停止します。[GDMの操作と確認範囲](GDM.md)

## 管理アプリ

v0.2.0でPython＋GTK4／libadwaitaによる「Hyalune 設定」を追加しました。通常は共通設定だけを表示し、個別調整は対象選択後に開きます。アプリ本体・デスクトップエントリー・アイコンを導入し、アプリ一覧から起動できます。通常外観のGUI・型付きプロファイル生成・選択Flatpakの同一journal反映・追従／個別値と、GDM専用権限窓口・画像／素材／ユーザー名色編集をVMで検証しています。実GDMの本人認証と実ログイン画面のレビューは残っています。[操作と構成](THEME-MANAGER.md)

Shell、GTKアプリ、拡張機能、Flatpakを共通設定と個別値で調整します。GDMは独立した適用操作です。同じ数値がすべての描画系で同じ見え方になるとは仮定せず、可読性と対応範囲を表示します。

GDMは、設定アプリで背景画像・面の不透明度と素材色・ユーザー名の文字色を編集できるようにしました。専用権限窓口と独立した適用・解除・復旧をVMで検証しています。背景と文字の組み合わせをプレビューし、実際の認証成功と次のログイン画面は本人のレビューで確認します。

初回の明示的なGDM適用で、そのとき導入利用者が使っている静止壁紙を初期背景として取り込むCLIを実装しました。以後の更新はGDM用に保存した画像を保持します。初期取り込みとデスクトップ壁紙の自動同期は別です。現在のデスクトップ画像を明示的に取り直す`background` CLIも追加しました。設定アプリでは、保存背景の保持・現在の壁紙・同梱背景・静止画像の選択を用意しました。[初回背景の動作と対応範囲](GDM.md#初回のデスクトップ壁紙取り込み)

テーマ導入後に追加したFlatpakは再検出し、対応状況・競合・起動状態を確認して選択適用できます。既存CLIの所有記録・共通ロック・復旧処理を再利用し、別の管理系で上書きしません。GDMをユーザーセッションの変更と一括で実行しません。

## Hyalune Lightと外観の切り替え

Hyalune Lightとして、明るい背景での文字・境界・重なりの読みやすさを別途検証し、Hyalune Darkと同様に復元可能な形で追加する予定です。現行DarkをLight対応済みとは扱いません。

将来の切り替えはGNOMEの設定画面のDark / Light選択への連動を第一候補とします。Shell・GTK・拡張・Flatpakを安全に連動させることが複雑な場合は、Hyaluneの管理アプリから切り替える方法を検討します。切り替え機能の設計・実装・検証は今後の工程であり、今回の改称には含めません。
